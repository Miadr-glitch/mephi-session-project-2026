# mephi-session-project-2026
EPHI Session Project 2026
- Номер студента: М265246
- Операционная система: Fedora Linux 44 Workstation
- Среда виртуализации: Oracle VirtualBox
- Веб-сервер: Nginx
- Имя хоста: mephi-2026.domain.local
- Веб-каталог: /mephi-web
Описание проекта
В рамках проекта выполнены настройка сетевого подключения, управление программным обеспечением, создание файловой системы, настройка веб-сервера Nginx, управление пользователями и группами, настройка прав доступа DAC, capabilities и SELinux, а также тестирование веб-страницы.
Результаты выполнения заданий
Раздел	Описание выполненной работы	Файлы подтверждения
1. Настройка системы	Настройка DHCP, имени хоста и проверка сетевой связности	ping.out, history.out
2. Управление программным обеспечением	Обновление системы, установка необходимых пакетов и работа с RPM	dnf.out, history.out
3. Файловые системы	Создание раздела, файловой системы ext4 и настройка автомонтирования	fstab, stat.out
4. Управление сервисами	Установка, настройка и запуск Nginx, проверка системного журнала	journalctl.out
5. Управление доступом	Создание пользователей и групп, настройка DAC и capabilities, проверка SELinux	passwd, group, getcap.out, getenforce.out, stat.out
6. Аутентификация	Настройка параметров паролей и ограничений входа	pwquality.conf
7. Тестирование	Создание веб-страницы и проверка её доступности	curl.out, mephi-screenshot.png
8. Публикация проекта	Размещение результатов выполнения проекта на GitHub	README.md и файлы репозиторияПроверка веб-сервера
